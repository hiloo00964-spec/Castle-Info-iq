# Castle Info Bot - GitHub Actions

بوت قلعة المعلومات العامة يعمل بواسطة GitHub Actions في مواعيد النشر المحددة.

## Gemini

تم تحويل التكامل إلى `google-genai` الحديث.

لا يوجد موديل Gemini ثابت داخل الكود:
- يستخدم `GEMINI_MODEL` إن كان متاحاً، وإلا يكتشف الموديلات النصية مرة واحدة عند غياب الكاش.
- يختار فقط الموديلات التي تدعم `generateContent`.
- يستبعد نماذج الصور والصوت والفيديو والبث المباشر والـ embeddings.
- يخزن نموذجًا أساسيًا وfallback واحدًا في `data.json` لتقليل طلبات اكتشاف الموديلات.
- إذا فشل النموذج الأساسي، يجرب fallback المخزن مرة واحدة فقط.

`GEMINI_MODEL` اختياري، وعند تغييره يعاد اكتشاف قائمة قصيرة من النماذج النصية المتاحة.

## Secrets

- BOT_TOKEN
- TELEGRAM_CHANNEL_ID
- GOOGLE_API_KEY
- API_ID
- API_HASH

اختياري:
- GEMINI_MODEL
