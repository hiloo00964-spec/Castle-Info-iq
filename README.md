# Castle Info Bot - GitHub Actions

بوت قلعة المعلومات العامة يعمل بواسطة GitHub Actions في مواعيد النشر المحددة.

## Gemini

تم تحويل التكامل إلى `google-genai` الحديث.

لا يوجد موديل Gemini ثابت داخل الكود:
- البوت يطلب قائمة الموديلات المتاحة حالياً من Gemini API في كل تشغيل.
- يختار فقط الموديلات التي تدعم `generateContent`.
- يستبعد نماذج الصور والصوت والفيديو والبث المباشر والـ embeddings.
- يرتب الموديلات الحالية ويجرب الأنسب أولاً.
- إذا فشل موديل بسبب الإيقاف أو الـ quota أو أي خطأ، ينتقل تلقائياً إلى موديل آخر متاح.
- إذا أضافت Google موديل جديداً متوافقاً، يمكن للكود اكتشافه بدون تعديل قائمة الموديلات يدوياً.

`GEMINI_MODEL` اختياري فقط لمن يريد تفضيل موديل محدد، وليس مطلوباً لتشغيل البوت.

## Secrets

- GOOGLE_API_KEY

اختياري:
